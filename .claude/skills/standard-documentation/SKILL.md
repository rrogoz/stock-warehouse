# Documentation standard

The rules live in [docs/standards/documentation.md](../../../docs/standards/documentation.md), with the fact homes in [ADR-009](../../../docs/adr/0009-repository-and-standards.md). Read them first; they win over this skill.

1. Find each fact's one home in the ADR-009 table; write it there and link to it from everywhere else.
2. Update every doc and config the change affects in the same pull request.
3. Use the [templates](../../../docs/templates/) for ADRs, specs, runbooks and standards.
4. Keep within the length limits; cut words before adding pages.
